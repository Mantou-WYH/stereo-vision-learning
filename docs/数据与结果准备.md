# 数据与结果准备

## ETH3D

来源：[官方数据页](https://www.eth3d.net/datasets)、[格式说明](https://www.eth3d.net/documentation)。使用 two-view training 照片、标定和参考视差。

本地布局为 `data/eth3d/<scene>/`，其中 `delivery_area_1s` 是木箱实验的输入。保留原生照片；本例左右主点相同，`doffs=0`，焦距 711.415 像素，基线 59.9701 毫米。

数据归原提供方所有，请自行按其条件获取。仓库不附带照片包、真值包或官方评分程序。

木箱实验读取 `notes/eth3d_validation/predictions/delivery_area_1s.npz` 中的 `classroom` 视差。这个文件是程序预测，不是参考视差。恢复时先阅读 `validate_eth3d_stereo.py` 的输入与保存约定；其完整运行涉及多场景比较，不是每次授课必做步骤。已保存预测存在时直接沿用。

随后按依赖顺序：

```powershell
python wood_depth_map_lab.py
python wood_point_cloud_lab.py
```

未知位置保留为未知，不补洞。深度换算或点云生成会继承原匹配误差，生成成功不代表精度验收。

## OpenCV Aloe

真实匹配示例来自 OpenCV 固定标签 4.12.0 的 `samples/data/aloeL.jpg`、`aloeR.jpg` 和 `aloeGT.png`，本地位于 `data/opencv-aloe/`。

参考编码与图像缩放影响比较，不能把 PNG 灰度直接解释成米数。该例没有可用基线与标定，不能据此做米制测距。

## 模拟实验

模拟箱体由项目程序生成。相机设定位姿和理想深度用于解释几何及检查误差来源；它们不证明真实数据精度。

根目录程序生成 `notes/synthetic_mapping/` 与 `notes/synthetic_motion/` 的输出。需要已有输出的程序，应先运行生成该输出的前一步。辅助图脚本保留在对应目录。
