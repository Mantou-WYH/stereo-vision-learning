## 实验连接

已有视差 → 同位置的前向深度 → 相机坐标三维点 → 按相机位姿放入共同坐标 → 合并或融合观测。

运动估计示例：第一帧像素与深度产生三维点；跨帧跟踪找到第二帧二维位置；PnP 求相机运动；再用估计位姿放置第二帧点云。模拟器的设定位姿用于对照，不能代替估计结果。

## 已整理的阶段

当前代码覆盖基础几何、真实 SGBM 与深度/点云，以及模拟融合和运动估计。最新连贯示例使用生成的两帧图像及理想深度，执行图像跟踪和 PnP，观察位姿误差引起的表面错位；它没有执行真实时序双目匹配或完整 SLAM。

示例运行、理解反馈、指导下实现和独立验收分别记录在本地。准备好的实验不代表全部课程通过。

## 研究路线

双目及评估基线 → 模型比较与训练基础 → 单目尺度对齐及监督可信度 → Teacher 到 Student 的蒸馏与消融 → 固定条件下建图评价与报告。

性能和准确度需在明确设备、数据、分辨率、计时范围与比较条件后报告。
